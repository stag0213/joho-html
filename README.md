# HTML体験ツール

高校「情報Ⅰ」向けに作成した、**HTML と CSS の基礎を体験的に学べる教材ツール**です。  
左側のエディタにコードを入力すると、右側のプレビューへリアルタイムで反映されます。

授業で使いやすいように、**サンプル読込、行番号表示、自動保存、エクスポート、スマートフォン対応**などの機能を備えています。

---

## 特徴

- HTML / CSS のリアルタイムプレビュー
- 行番号付きエディタ
- サンプルコードの読み込み
- ローカルストレージによる自動保存 / 復元
- クリア機能
- エクスポート機能
  - 個別ファイル出力（HTML / CSS）
  - 統合ファイル出力（1つの HTML ファイル）
- スマートフォン対応レスポンシブデザイン
- Google Sites など iframe 埋め込み環境への対応版あり
- 外部リンクをプレビュー内ではなく**自動で別タブで開く**仕様

---

## 使い方

1. HTML または CSS を入力する
2. 右側のプレビューで結果を確認する
3. 必要に応じてサンプルコードを読み込む
4. 完成したらエクスポート機能で保存する

### 例

```html
<h1>こんにちは</h1>
<p>これはHTML体験ツールのサンプルです。</p>
<a href="https://www.yahoo.co.jp">Yahoo! JAPAN</a>
```

```css
h1 {
  color: royalblue;
}

p {
  font-size: 18px;
}
```

## 外部リンクの仕様

外部サイトへのリンク（`https://` または `http://` で始まるリンク）は、プレビュー内で開こうとすると埋め込み制限により表示できない場合があります。  
そのため本ツールでは、**外部リンクをクリックすると自動で別タブで開く**ようにしています。

## 注意事項

- 自動保存にはブラウザのローカルストレージを使用します
- ブラウザの閲覧データ削除を行うと保存内容が消える場合があります
- Google Sites など iframe 環境では、一部ブラウザ仕様の影響を受けることがあります
- 外部サイトの表示可否は、相手側サイトのセキュリティ設定に依存します

---

## トラブルシューティング

### プレビューに反映されない
- HTML の閉じタグ漏れを確認してください
- CSS の `{}` の対応を確認してください

### 外部リンクが開かない
- ブラウザのポップアップブロック設定を確認してください
- 埋め込み先サービス側の制限を確認してください

### 保存内容が復元されない
- 同じブラウザ / 同じ端末で開いているか確認してください
- ブラウザのデータ削除をしていないか確認してください
